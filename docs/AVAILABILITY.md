# Availability and manuscript mapping

This version is based on existing source code and saved experimental evidence. It does not introduce new experiments or infer missing results.

| Manuscript table | Included material | Scope |
|---|---|---|
| I: cross-model evaluation | FlashOCC-based evaluator only | ALOcc/GDFusion, OPUS and TPVFormer/GaussRender experiment packages are not included |
| II: regional discrimination | `evidence/planner/bootstrap_ci.json`, `evidence/scene_statistics/` | Saved point estimates and confidence intervals; point estimates can be recomputed |
| III: native operating points | `evidence/native/` | Per-seed JSON results; group means can be recomputed |
| IV: temporal models | `configs/temporal/`, `evidence/temporal/` | Configurations and saved statistics; temporal checkpoints and per-scene bootstrap inputs are not included |
| V: matched error placement | None | Complete paired-intervention experiment package is not included |
| VI: independent planner | None | Complete independent-planner experiment package is not included; the fixed-path proxy is a different experiment |
| VII: paired proxy differences | `evidence/planner/bootstrap_ci.json` | Saved paired confidence intervals |
| VIII: fixed-path proxy | `evidence/planner/per_scene/`, summary JSON/CSV | Complete 75-scene merged counters for the included model seeds |
| IX: SurroundOcc transfer | `evidence/surroundocc/` | Saved per-scene statistics and summary; raw GT, model checkpoints and a complete inference adapter are not included |

## Data and checkpoints

Download nuScenes and occupancy labels from their official providers under their own access terms. They are not redistributed here. Training also requires detection-pretrained weights, and reproducing inference for a specific published run requires that run's trained checkpoint. Neither is included in this archive.

Do not substitute the upstream FlashOCC public checkpoint for a paper RiskOcc checkpoint and describe the resulting score as a reproduction of the paper.

## Statistics schema

- `evidence/scene_statistics/g0_*.npz`: 150 scene tokens; 1,200-bin regional positive/negative histograms; near-field free/high-risk histograms; degradation and native FN counters. `scene_split` is 0 for canonical tune and 1 for canonical report. Older aggregated prediction-group histograms and partial legacy planner fields were excluded because they used a different split. The retained histogram/count arrays are unchanged.
- `evidence/planner/per_scene/*.npz`: 75 canonical report scenes, 15,060 path records per model seed, tune-derived threshold index, and unsafe/over-block counters. These are the complete merged counters, not the partial legacy arrays.
- `evidence/surroundocc/per_scene/*.npz`: saved transfer-evaluation arrays. Summary confidence intervals are archived outputs, not regenerated by the lightweight verifier.
- `evidence/paper_tables.json`: numeric text from Tables II, III, IV, VII, VIII and IX of the 2026-11-10 manuscript, for release verification. The full manuscript is not included.

`realized_blocking_at_fp_0p10` is an inherited result key for **NearFP**, not the path over-block rate. NearFP and path over-block must be reported separately.

Uniform and focal controls contain two seeds; CE, RiskOcc and CE+Tversky contain three seeds in the spatial proxy block. Means are means of per-seed metrics, not pooled predictions or averaged voxel outputs.
